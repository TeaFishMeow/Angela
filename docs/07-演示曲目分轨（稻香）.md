## 0. 为什么稻香要"人工编排高低声部"

- 稻香是**周杰伦独唱**，不是天然对唱。
- 合唱模式需要两条人声线：**Angela=高声部**、**Neo=低声部**。
- 自动分声部（按声像/频率把一条人声拆两半）对独唱曲**不可靠**，3 小时 demo 不赌。
- **结论：用"移调复制法"造出两条线**，简单、稳定、够用。

## 1. 产物清单（务必命名一致）

放进 `assets/songs/daoxiang/`：

| 文件 | 用途 | 谁产生 |
|------|------|--------|
| `source.mp3` | 原曲（.gitignore 排除） | 你 |
| `instrumental.wav` | 伴奏（无人声） | 你（Demucs） |
| `vocals_full.wav` | 完整人声 | 你（Demucs） |
| `vocals_neo.wav` | 低声部 = 原人声 | 你（= vocals_full） |
| `vocals_angela.wav` | 高声部 = 人声上移（给 B 做 RVC） | 你（移调） |
| `mv.mp4` | 背景视频 | 你（找/截） |
| `cover.jpg` | 选歌封面 | 你 |
| `mix.wav` | 成片（B 混） | 队友 B |
| `vocals_angela_rvc.wav` | Angela 音色高声部（口型源，B 产出） | 队友 B |
| `lyrics/visemes/actions/song.json` | 轨道与清单 | 你 + B |

> **同起点约定**：所有 wav 都从原曲同一时刻开始，**不要单独 trim 静音**，否则口型/歌词会错位。

## 2. 第一步：分轨（Demucs）

```bash
# 装（任选其一）
pip install demucs            # 或 conda
# 或用 Ultimate Vocal Remover (UVR5) GUI，模型 htdemucs / htdemucs_ft

# 分离 → vocals.wav / no_drums / bass / other（htdemucs 默认 4 轨）
demucs -n htdemucs --two-stems vocals "source.mp3" -o out/
# 产物：out/htdemucs/source/vocals.wav  和  out/htdemucs/source/no_vocals.wav
```
- `vocals.wav` → 重命名 `vocals_full.wav`。
- `no_vocals.wav` → 重命名 `instrumental.wav`（伴奏，含原伴奏+和声）。
- 听一遍 `instrumental.wav`：人声残留多就换 `htdemucs_ft`（更干净但慢）或 UVR5 `MDX23C`。

## 3. 第二步：造高低声部（移调复制法）

**Neo 低声部**：直接用原人声。
```bash
ffmpeg -y -i vocals_full.wav -ac 1 -ar 44100 vocals_neo.wav
```

**Angela 高声部**：人声整体上移，让 Angela 听感"更高"，配合女声 RVC 自然：
```bash
# asetrate 升采样基频 = 升调；+12 半音≈一个八度，先试 +5~+7 半音更自然
ffmpeg -y -i vocals_full.wav -filter_complex "asetrate=44100*2^(7/12),aresample=44100,atempo=2^(-7/12)" vocals_angela.wav
```
- 解释：`asetrate` 升调、`atempo` 把时长拉回原速（否则会变快变短）。
- **听感检查**：`vocals_angela.wav` 应明显更"高/尖"。给 RVC 当输入即可（RVC 还会再塑音色）。
- 觉得太刺耳：降到 +5 半音，或保留原调、仅靠 RVC 的 `pitch_shift +12` 提高女声音高（更省事，见 §4 取舍）。

> **取舍**：如果时间紧，可以**不单独移调**，直接把 `vocals_full.wav` 复制一份当 `vocals_angela.wav`，
> 高低声部的"区分"完全交给 RVC（女声 +12）vs 原声。两条声部同时唱会"叠"，demo 听感是"男女和声"，能接受。
> 要更干净就用本节的移调法。

## 4. 第三步：把素材交给队友 B

交付：`instrumental.wav`、`vocals_neo.wav`、`vocals_angela.wav`（同起点、44.1k/单声道或立体声一致）。
B 会做：RVC(angela) → 混音 `mix.wav` → 由 `vocals_angela_rvc.wav` 烘焙 `visemes.json`（见 `04`）。

**你要盯的一件事**：`mix.wav` 出来后，**用它重新打歌词时间戳**（§5），因为混音可能让起点/时长与原曲差几十毫秒。

## 5. 第四步：打歌词时间戳（lyrics.json）

工具任选：
- **Audacity**：导入 `mix.wav`，逐句听，在波形上打标签 → 导出标签 → 转成 `lyrics.json`。
- ** quicker**：找一个现成 LRC，用脚本按"前奏时长偏移"整体平移对齐 `mix.wav`。

歌词（稻香，节选，用于 demo；时间戳是占位，**以你 mix.wav 实测为准**）：
```
对这个世界如果你有太多的抱怨
跌倒了就不敢继续往前走
为什么人要这么的脆弱 堕落
请你打开电视看看
多少人为生命在努力勇敢的走下去
我们是不是该知足
珍惜一切 就算没有拥有
……（副歌）
不要这么容易就想放弃 就像我说的
追不到的梦想 换个梦不就得了
……
```
- **只打主歌+副歌**即可，间奏/尾奏留空。
- 每句两条记录（`part:high` 和 `part:low`，文本相同），形成"两人合唱"；想体现"交替"就在某些句只给一个 part。
- 字段格式严格按 `03 §2`。

小工具（把 Audacity 标签 txt 转 lyrics.json）：
```python
# labels.txt 每行: start \t end \t text
import json
lines=[]
for ln in open("labels.txt",encoding="utf-8"):
    s,e,t=ln.rstrip("\n").split("\t"); s,e=float(s),float(e)
    for part,spk in (("high","Angela"),("low","Neo")):
        lines.append({"t":round(s,2),"d":round(e-s,2),"part":part,"speaker":spk,"text":t})
lines.sort(key=lambda x:(x["t"],0 if x["part"]=="high" else 1))
json.dump({"song":"daoxiang","fps":30,"lines":lines},open("lyrics.json","w",encoding="utf-8"),ensure_ascii=False,indent=2)
```

## 6. 第五步：背景 MV

- 稻香官方 MV 或演唱版视频；截到与 `mix.wav` **同长度**（多了裁、短了循环/补黑底）。
- 编码：`mp4 / H.264 + AAC`，1080p 够。
- 放 `assets/songs/daoxiang/mv.mp4`（.gitignore 排除）。
- **没有 MV**：用一张稻香主题背景图 + 频谱可视化 canvas 代替（见 `08` 兜底）。

## 7. 第六步：song.json 与动作
