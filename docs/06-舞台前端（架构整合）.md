## 3. 编排状态机（两场）

```
 idle ─scene.load(传奇)→ ANGELA.intro → singing(传奇,Angela) → outro
                                            │ (next.scene)
                                   scene.load(因为爱情)→ NEO.intro → singing(因为爱情,Neo) → outro → end
```

`orchestrator.js` 骨架：
```js
const order = ["chuanqi", "yinwei-aiqing"]; let idx = 0;
ws.on("scene.list",   d => renderScenePicker(d.scenes));
ws.on("scene.loaded", d => { scene=d; lyrics.prepare(d); });
ws.on("character.set",d => stage.switchTo(d.name));        // Angela/Neo
ws.on("scene.start",  d => startSinging(d));
ws.on("scene.end",    () => ws.send("outro.start",{id:scene.id}));
ws.on("scene.tick",   d => clock.notify(d.t));
ws.on("viseme.frame", d => stage.setViseme(d.params));     // 对白期
ws.on("action.set",   d => stage.playMotion(d.name,d));
ws.on("subtitle",     d => subtitle.show(d));

function startScene(){ ws.send("scene.load",{id:order[idx]}); }
function nextScene(){ idx++; if(idx<order.length) startScene(); else end(); }
function startSinging({id,backingUrl,t0}){
  audio.src=backingUrl; audio.play(); clock.attach(audio);
  clock.loadTracks(scene.tracks); lyrics.mount(scene);
  stage.playMotion(scene.character==="angela"?"singing_high":"singing_low",{loop:true});
  loop();
}
```

## 4. 主时钟与主循环（合唱期，渲染权威）

```js
// clock.js：权威 = 伴奏带 <audio>.currentTime
function loop(){
  if(phase!=="singing") return;
  const t = audio.currentTime;
  lyrics.update(t);                                   // 双栏高亮（digital/teammateC）
  stage.setViseme(clock.visemeAt(t));                 // 数字人口型
  const seg = clock.actionAt(t);
  if(seg && seg!==curAction){ stage.playMotion(seg.action,seg); curAction=seg; }
  requestAnimationFrame(loop);
}
```
- 只读 `audio.currentTime`，不靠 WS 逐帧（`00 §5`、`02 §5`）。
- **队友C 同步**：队友C 听调音台返听里的**同一伴奏带**；屏幕歌词高亮 `teammateC` 行 = 提词。

## 5. 双声部歌词（lyrics.js）

- 按 `part` 分两栏：左/中 = **数字人声部**（digital），另一栏 = **队友C 现场声部**（teammateC）。
- `update(t)`：高亮 `[t,t+d]` 包含 `t` 的行；`teammateC` 行高亮提示队友C 该唱。
- 传奇（unison）：两栏同句同时间（齐唱）；因为爱情（duet）：男女交替。
- 字幕（对白期）单独组件。

## 7. WS 客户端（ws-client.js）

- `send(type,data)` 自动填 `seq`+`ts`；1/2/4s 退避重连，重连后重发 `hello`+重载当前场。

## 8. 离线/兜底

- 后端 `/ws` 连不上 → `OFFLINE`：本地 `fetch` scene.json，本地播 `backing.wav`，本地拉轨道；对白用**预录 wav**（B 提前生成）。
- MV 缺失 → 背景图 / 频谱 canvas。
- 这样后端/网络挂了仍能走完两场。

## 9. 场选择 UI

- 两张卡片（传奇/Angela、因为爱情/Neo）；点 → `scene.load`。
- 路演默认**自动串行**两场（`order`），也支持手动跳场。
