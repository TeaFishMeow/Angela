## 4. ② RVC 变声（见 09 详）

```bash
# 因为爱情：男声 → Neo
rvc infer -m voice/models/neo_male.pth -i "因为爱情 男声_vocals.wav" \
          -o "因为爱情 男声_vocals_neo_rvc.wav" -p 0 -f0 rmvpe \
          -ir voice/models/neo_male.index
# 传奇：人声 → Angela
rvc infer -m voice/models/angela_female.pth -i "传奇 vocals.wav" \
          -o "传奇 vocals_angela_rvc.wav" -p 0 -f0 rmvpe \
          -ir voice/models/angela_female.index
```
- `-p pitch_shift`：用同性别模型时一般 0；若男模转女声 +12。以听感为准（见 `09 §调参`）。
- 5070Ti 12G 跑 inference 远快于实时，两曲几分钟出。
- **务必听验**：电音/失真严重就换模型/调参（`09 §质量`），别直接上。

## 5. ③ 预混 → `backing.wav`（★伴奏带）

```bash
# 因为爱情：伴奏(已含伴奏层) + Neo 人声
ffmpeg -y -i "因为爱情 男声_instrumental.wav" -i "因为爱情 男声_vocals_neo_rvc.wav" \
  -filter_complex "[0:a]volume=0.9[a];[1:a]volume=0.95,aresample=async=1[b];[a][b]amix=inputs=2:duration=longest[m]" \
  -map "[m]" -ac 2 -ar 44100 "因为爱情_backing.wav"

# 传奇：伴奏 + Angela 人声（齐唱：队友C 同旋律现场唱，不在带里）
ffmpeg -y -i "传奇 instrumental.wav" -i "传奇 vocals_angela_rvc.wav" \
  -filter_complex "[0:a]volume=0.85[a];[1:a]volume=0.95[b];[a][b]amix=inputs=2:duration=longest[m]" \
  -map "[m]" -ac 2 -ar 44100 "传奇_backing.wav"
```
- **关键**：`backing.wav` = 伴奏 + 数字人声，**不含队友C 唱的部分**。
- 给数字人声加一点混响更舞台：`[b]aecho=...` 或省略。
- **同起点**：`backing.wav`、`vocal_rvc.wav`、`lyrics/visemes/actions` 都从同一 0 点，勿单独 trim。

### 伴奏带双路输出（现场必做）
```
backing.wav → ① 舞台电脑 <audio>（驱动 MV/歌词/口型时钟）
            → ② 调音台 lineout（与队友C 麦混音 → PA + 队友C 返听）
```
- ①② 是**同一文件**播放（电脑播放给屏幕/口型；调音台那路可由电脑 lineout 或单独播放器）。
- 现场建议：电脑一路 HDMI/音频给舞台，一路 3.5mm/USB 给调音台；或调音台直接吃电脑主输出。

## 6. ④ 烘焙 `visemes.json`

```python
# bake_visemes.py
import librosa, numpy as np, json
y, sr = librosa.load("因为爱情 男声_vocals_neo_rvc.wav", sr=22050, mono=True)
hop = sr // 30
rms = librosa.feature.rms(y=y, frame_length=512, hop_length=hop)[0]
peak = max(np.quantile(rms, 0.95), 1e-6)
openY = np.convolve(np.clip(rms/peak, 0, 1), np.ones(3)/3, mode="same")
json.dump({"scene":"yinwei-aiqing","fps":30,"params":["ParamMouthOpenY"],"start":0.0,
           "frames":[[round(float(v),3)] for v in openY]},
          open("visemes.json","w",encoding="utf-8"))
```

## 8. FastAPI 骨架（scene 语义）

```python
# app.py（精简）
from fastapi import FastAPI, WebSocket
from fastapi.staticfiles import StaticFiles
from pathlib import Path
import json, asyncio

ROOT = Path("../../演示用例").resolve()
app = FastAPI()
app.mount("/assets", StaticFiles(directory=ROOT), name="assets")

def scene_ids(): return [p.parent.name for p in ROOT.glob("*_分轨/scene.json")]
def load_scene(sid): return json.loads((ROOT/f"{sid}_分轨/scene.json").read_text(encoding="utf-8"))
# 注：scene.json 也可集中放一处；这里按 _分轨/ 就近放

@app.get("/api/scenes")
def scenes(): return [load_scene(s) for s in scene_ids()]

@app.get("/api/scenes/{sid}")
def scene(sid): return load_scene(sid)

@app.websocket("/ws")
async def ws(c: WebSocket):
    await c.accept()
    async for raw in iter_msgs(c):                 # 信封
        m = json.loads(raw); t=m["type"]; d=m.get("data",{})
        if t=="hello":        await send(c,"hello",{"proto":"0.2"}); await send(c,"scene.list",{"scenes":[{"id":s,**load_scene(s)} for s in scene_ids()]})
        elif t=="scene.load":
            s=load_scene(d["id"])
            await send(c,"scene.loaded",{"id":d["id"],"title":s["title"],"character":s["character"],"manifest":s})
            await send(c,"character.set",{"name":s["character"],"model":s.get("character_model")})
            await run_tts(c, s["dialogue"].get("intro",[]))   # 开场对白
        elif t=="scene.start":
            s=load_scene(d["id"])
            await send(c,"scene.tracks",{k:{"url":f"/assets/{s['tracks'][k]}"} for k in ("lyrics","visemes","actions")})
            await send(c,"action.set",{"name":"singing_high" if s["character"]=="angela" else "singing_low","loop":True})
            await send(c,"scene.start",{"id":d["id"],"backingUrl":f"/assets/{s['audio']['backing']}","t0":0})
            asyncio.create_task(tick(c, s["duration"]))
            await asyncio.sleep(s["duration"]); await send(c,"scene.end",{"id":d["id"]})
        elif t=="outro.start":
            await run_tts(c, load_scene(d["id"])["dialogue"].get("outro",[]))
```
（`send/iter_msgs/tick/run_tts` 按 `02` 实现；TTS 同 `04` 旧版的 edge-tts 流式 + 实时口型。）
