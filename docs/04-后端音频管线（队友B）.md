## 4. ② RVC 变声

用 Applio/RVC 把 `vocals_angela.wav` 转成 Angela 音色：

```bash

          -o vocals_angela_rvc.wav -p 12 -f0 rmvpe -ir assets/models/angela.index
# -p pitch_shift：女声通常 +12；以听感为准
```
- 没有训练好的 Angela 模型？先用一个**通用女声 RVC 模型**占位，demo 前能换就换（见 `01 §风险`）。
- 输出 `vocals_angela_rvc.wav` 作为**口型数据源**（因为它最接近最终听感）。

## 5. ③ 混音 → `mix.wav`

用 ffmpeg 一次混好（音量按听感调）：

```bash
ffmpeg -y \
  -i instrumental.wav \
  -i vocals_angela_rvc.wav \
  -i vocals_neo.wav \
  -filter_complex "[1:a]volume=0.9[a];[2:a]volume=0.8,aresample=async=1[n];[0:a]volume=0.85[bg];[bg][a][n]amix=inputs=3:duration=longest:dropout_transition=0[m]" \
  -map "[m]" -ac 2 -ar 44100 mix.wav
```
- 建议**先混人声再合伴奏**：人声之间 `amix` → 轻混响 → 再与伴奏 `amix`，避免人声被压。
- 给 Angela 高声部加一点混响更"舞台"：`aecho`/`freeverb` 或省略。
- 产物 `mix.wav` 与 `vocals_angela_rvc.wav`、`lyrics/visemes/actions` **必须同起点**（都从 0 开始，不要 trim 前导静音不一致）。

## 6. ④ 烘焙 `visemes.json`（librosa RMS）

```python
# bake.py
import librosa, numpy as np, json, soundfile as sf
y, sr = librosa.load("vocals_angela_rvc.wav", sr=22050, mono=True)
hop = sr // 30
rms = librosa.feature.rms(y=y, frame_length=512, hop_length=hop)[0]
peak = max(np.quantile(rms, 0.95), 1e-6)
openY = np.clip(rms / peak, 0, 1)
# 三帧平滑
k = np.ones(3)/3
openY = np.convolve(openY, k, mode="same")
frames = [[round(float(v), 3)] for v in openY]
json.dump({"song":"daoxiang","fps":30,"params":["ParamMouthOpenY"],"start":0.0,"frames":frames},
          open("visemes.json","w"), ensure_ascii=False)
```
- 想更精细：用 `aeneas`/`whisper` 做强制对齐拿音素，估 `ParamMouthForm`（嘴角）。**本版按幅度法即可**，A 在数字人侧调增益。

## 8. FastAPI 骨架

```python
# app.py（精简）
from fastapi import FastAPI, WebSocket
from fastapi.staticfiles import StaticFiles
from pathlib import Path
import json, asyncio, edge_tts, base64, numpy as np, io, librosa

ASSETS = Path("../../assets").resolve()
app = FastAPI()
app.mount("/assets", StaticFiles(directory=ASSETS), name="assets")

def load_song(sid): return json.loads((ASSETS/f"songs/{sid}/song.json").read_text(encoding="utf-8"))

@app.get("/api/songs")
def songs(): return [load_song(s.parent.name) for s in (ASSETS/"songs").glob("*/song.json")]

@app.get("/api/songs/{sid}")
def song(sid): return load_song(sid)

@app.websocket("/ws")
async def ws(c: WebSocket):
    await c.accept(); st = {"phase":"select"}
    async for raw in iter_over(c):                 # 收信封
        msg = json.loads(raw); t = msg["type"]; d = msg.get("data",{})
        if t == "hello":
            await send(c, "hello", {"songs":[s["id"] for s in songs()]})
        elif t == "song.select":
            await send(c, "phase.change", {"phase":"select"})
            await send(c, "song.loaded", {"id":d["id"], **load_song(d["id"])})
            await run_tts(c, load_song(d["id"])["dialogue"]["selected"])  # 选歌对白
        elif t == "song.start":
            s = load_song(d["id"])
            await send(c, "song.tracks", {k:{"url":f"/assets/songs/{d['id']}/{k}.json"} for k in ("lyrics","visemes","actions")})
            await send(c, "action.set", {"name":"singing_high","loop":True})
            await send(c, "song.start", {"id":d["id"], "mixUrl":f"/assets/songs/{d['id']}/mix.wav","t0":0})
            st["phase"]="singing"; asyncio.create_task(tick_loop(c, s["duration"]))
            await asyncio.sleep(s["duration"])      # 粗略等到唱完
            await send(c, "song.end", {"id":d["id"]}); st["phase"]="finale"
            await send(c, "phase.change", {"phase":"finale"})
            await run_tts(c, s["dialogue"]["finale"])
```
（`send`/`iter_over`/`tick_loop` 是信封封装与 10Hz 心跳，按 `02` 实现。）

## 9. TTS + 实时口型（幕一/三）

```python
# tts.py 思路
async def run_tts(c, lines):
    seq = 0
    for text in lines:
        seq += 1
        await send(c, "subtitle", {"speaker":"Angela","text":text})
        await send(c, "action.set", {"name":"talk","loop":True})
        await send(c, "tts.start", {"seq":seq,"voice":"angela"})
        # 1) edge-tts 流式生成 → 边收 PCM 边算 RMS 边推 viseme 帧 + 边推音频分片
        async for chunk in stream_tts_pcm(text):
            frames = rms_to_viseme(chunk, sr=24000)   # 30fps 帧
            for f in frames:
                await send(c, "viseme.frame", {"t":f.t, "params":f.params})
            await send(c, "tts.audio", {"seq":seq,"mime":"audio/wav","b64":base64.b64encode(chunk).decode()})
        await send(c, "tts.end", {"seq":seq})
    await send(c, "action.set", {"name":"idle","loop":True})
```
- **音色统一**：edge-tts 出来的女声可再过一次 RVC（Angela 模型）让对白音色和唱歌一致——能做就做，来不及就用 edge-tts 原声（zh-CN-XiaoyiNeural 等）。
- **延迟**：TTS 流式 + 边算边推，首字节 <500ms 目标；超时就预生成整段 wav 再推。

## 10. mock_ws.py（与整合者共建）

让前端/数字人**不必等你**就能跑三幕。要点：
- 收 `hello` → 回歌单（读 `data/samples`）。
- 收 `song.select` → 推 `phase.change` + 假 `song.loaded` + 一句预录/静音 TTS。
- 收 `song.start` → 推 `song.tracks`（指向 `data/samples`）+ `song.start`（指向一个任意可用 wav）+ 10Hz `song.tick` 到 duration → `song.end` → finale。
- 行为与真后端**信封/字段完全一致**，仅数据是假的。整合者照 `02` 抄即可（你也可在 `packages/backend/mock/mock_ws.py` 提供实现）。
