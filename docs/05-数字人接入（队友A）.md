# 05 · 数字人接入（队友 A 专篇）

> 你负责把 **Angela（Live2D）** 接进舞台：加载模型、暴露给前端调用的 JS API、用口型/动作数据驱动她、
> 在舞台右侧透明叠层渲染。本文给出 **API 契约**、**口型/动作映射**、**最小实现**和**交付物**。

参考：`00 架构`、`02 接口契约`、`03 数据格式`。

---

## 0. 定位：数字人 = 前端组件

- 数字人**不是独立进程**，而是跑在舞台前端里的一个 JS 模块（`packages/character/`）。
- 用 **pixi-live2d-display**（基于 pixi.js + Cubism Web SDK），在透明 `<canvas>` 上渲染。
- 你的模块对外暴露一个稳定 API（见 §2），舞台通过它驱动；舞台把后端 WS 的 `viseme.frame`/`action.set` 转成 API 调用。

## 1. 环境与依赖

```bash
cd packages/character
npm init -y
npm install pixi.js@7 pixi-live2d-display@0.4 cubism4-sdk   # Cubism4 模型
# 或用 CDN（最快）：<script src="https://cubism.live2d.com/sdk-web/cubism4/live2dcubismcore.min.js"></script>
#                 <script src="https://cdn.jsdelivr.net/npm/pixi.js@7.x/dist/pixi.min.js"></script>

```
- **模型**：放 `packages/character/models/angela/`（含 `angela.model3.json`、`.moc3`、贴图、动作 `.motion3.json`）。
- 现成 demo 模型可先用（如官方 Hiyori/Haru），名字挂成 Angela。

## 2. 你的 API 契约（舞台照这个调）

```js
// packages/character/character.js
export class Character {
  /** 挂载到 canvas，返回实例 */
  static async mount(canvasEl, opts) // opts: { model: 'models/angela/angela.model3.json', scale, anchor }

  /** 口型：合唱期由前端按 t 查表传入；对白期由前端转交 WS 的 viseme.frame */
  setViseme(params)                  // params: { ParamMouthOpenY: 0..1, ParamMouthForm?: 0..1 }

  /** 动作：name 必须是 §4 动作词表里的 */
  playMotion(name, { loop=false, blend=0.3, dur, then }={})
  /** 表情（可选） */
  setExpression(name)                // 如 'smile'
  /** 待机呼吸（默认） */
  idle()
  /** 销毁 */
  destroy()
}
```

舞台侧用法（示意，完整见 `06`）：
```js
import { Character } from '../character/character.js';
const angela = await Character.mount(document.getElementById('cv'), { model:'models/angela/angela.model3.json' });
angela.idle();
// 合唱主循环
function frame(){ const t=audio.currentTime; angela.setViseme(visemes.lookup(t)); /* ... */ requestAnimationFrame(frame); }
```

## 3. 口型映射（Live2D 参数）

Live2D Cubism4 嘴部参数：

| 参数 | 范围 | 含义 | 数据来源 |
|------|------|------|----------|
| `ParamMouthOpenY` | 0..1（或 0..0.8 看模型） | 张嘴幅度 | visemes（RMS）★必需 |
| `ParamMouthForm` | -1..1 | 嘴形（笑/抿） | 可选，固定或音素估 |
| `ParamBreath` | 0..1 | 呼吸（idle 用） | 模型自驱动 |

实现要点：
- pixi-live2d-display 每帧前设置参数：`model.internalModel.coreModel.setParameterValueById('ParamMouthOpenY', v)`，或注册 `update` 钩子。
- **增益/平滑在你这里调**：后端给的是 0..1 归一化值；你按模型嘴的大小调 `gain`（如 ×0.9），并对突变做 lerp 平滑避免抖。
- 静音段（v≈0）保证闭嘴；爆破音可加一点点过冲。
- `ParamMouthForm` 暂可固定一个轻微微笑值（如 0.3）让画面更自然。

伪代码：
```js
let cur = 0, gain = 0.9;
function applyViseme(p){
  const target = (p.ParamMouthOpenY ?? 0) * gain;
  cur += (target - cur) * 0.5;            // lerp 平滑
  model.internalModel.coreModel.setParameterValueById('ParamMouthOpenY', cur);
}
// 注册到模型每帧更新（pixi-live2d-display 提供 'beforeUpdate' 或重写 update）
```

## 4. 动作词表（= Live2D motion 组名）

你需要在模型里准备这些 motion 组（`.motion3.json` 文件名或组名对应）：

| name | 必备 | 说明 |
|------|------|------|
| `idle` | ✅ | 待机呼吸 + 偶尔眨眼 |
| `talk` | ✅ | 说话时身体微动（配合对白期口型） |
| `singing_high` | ✅ | 唱高声部：轻摆 + 手部动作 |
| `singing_low` | ⬜ | 唱低声部（备） |
| `sway` | ⬜ | 左右摇摆 |
| `wave` | ⬜ | 挥手 |
| `bow` | ⬜ | 鞠躬 |
| `point` | ⬜ | 指向 |

> 动作名与 `actions.json`、`action.set` 的 `name` **一一对应**（见 `03 §4`）。
> 缺动作的：用 `idle` 顶替，别报错。

`playMotion` 实现：
```js
playMotion(name, {loop=false, blend=0.3, dur, then}={}){
  const g = this.model.motion(name);           // 取该组随机一条
  this.model.motion(name, 0, priority=loop?2:3);// priority 3=force
  if(!loop && dur){ setTimeout(()=> this.playMotion(then||'idle', {loop:true}), dur*1000); }
}
```

## 5. 渲染与叠层

- canvas **透明**：`background: transparent; mix-blend-mode: normal`；pixi `app.renderer.background.alpha = 0`。
- 定位舞台右侧、垂直居中、底部对齐（站姿）。尺寸适配：模型高度 ≈ 舞台高 90%。
- 多分辨率：监听 resize 重算 `scale`/`position`。
- 性能：60fps；口型/动作都是轻量参数，无压力。
- **自动眨眼/呼吸**别关（pixi-live2d-display 默认开），让待机不僵。

## 6. 与 WS 数据的衔接（你不用直接连 WS）

后端 → 舞台 → 你的模块。你只需保证 API 稳定；舞台负责：
- 对白期收到 `viseme.frame` → `angela.setViseme(frame.params)`；收到 `action.set` → `angela.playMotion(name,...)`。
- 合唱期舞台自己按 `audio.currentTime` 查 `visemes.json` → `setViseme()`；查 `actions.json` → `playMotion()`。

> 若你想让数字人**独立连 WS**（解耦舞台），也行：在模块内 `new WebSocket('/ws')`，订阅 `viseme.frame`/`action.set`/`song.tick`，合唱期用 `song.tick` 的 `t` 当时钟（精度略低于音频时钟，但可接受）。**推荐仍走舞台转发**，保证与歌词同源。
