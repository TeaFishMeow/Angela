# 02 · 接口契约（★ 三方对齐的唯一真源 · 路演版）

> 任何跨模块的数据形状都在这里冻结。字段名、单位、枚举值三方**必须**一致。
> 路演版变化：用 **scene（场）** 作为主单位（= 一曲 + 一个数字人 + 声部关系 + 对白），
> 新增 **character（数字人）切换**；队友C 麦克风**不走本协议**（走调音台 PA）。

---

## 0. 端点总览

| 通道 | 地址 | 用途 |
|------|------|------|
| REST | `GET /api/scenes` | 场列表（场1传奇/场2因为爱情） |
| REST | `GET /api/scenes/{id}` | 单场 manifest（伴奏带/轨道/对白/角色） |
| REST | `GET /assets/{path}` | 静态资源（伴奏带、MV、模型、轨道 json） |
| REST | `POST /api/tts` | 一次性 TTS：`{text, voice}` → audio/wav（兜底） |
| WS | `ws://host/ws` | 实时：控制 / 事件 / TTS / 口型帧 |

## 1. WebSocket 消息信封

```json
{ "type": "<MessageType>", "seq": 0, "ts": 0.0, "data": { ... } }
```
- `seq`：单调递增（乱序/去重）；`ts`：秒（合唱期=相对伴奏带起点；对白期=相对该 TTS 段；事件可为 0）。

## 2. 消息类型总表

### 2.1 前端 → 后端（控制）

| type | data | 何时发 | 后端动作 |
|------|------|--------|----------|
| `hello` | `{role:"stage"}` | 连接后 | 回 `hello` + `scene.list` |
| `scene.load` | `{id:"chuanqi"\|"yinwei-aiqing"}` | 切到某场 | 回 `scene.loaded`（含 character）；可触发 intro TTS |
| `scene.start` | `{id}` | 进合唱 | 推 `scene.tracks`+`character.set`+`scene.start` |
| `scene.stop` | `{}` | 中途停 | 回 `scene.end`，回到待场 |
| `outro.start` | `{id}` | 唱完 | 触发该场 outro TTS |
| `next.scene` | `{}` | 场间 | 切下一场（scene.load 下一场） |
| `tts.request` | `{text}` | （可选）临时 TTS | 推 `tts.*` |

### 2.2 后端 → 前端（事件 / 数据 / 流）

| type | data | 含义 | 消费方 |
|------|------|------|--------|
| `hello` | `{role:"backend", proto:"0.2"}` | 握手 | 舞台 |
| `scene.list` | `{scenes:[{id,title,character,...}]}` | 两场清单 | 舞台（选场 UI） |
| `scene.loaded` | `{id, title, character, manifest}` | 场已加载 | 舞台 + 数字人 |
| **`character.set`** | `{name:"angela"\|"neo", model}` | **切数字人模型** | 数字人（switchTo） |
| `scene.tracks` | `{lyrics, visemes, actions}`（内联或 `{url}`） | 合唱期一次性下发轨道 | 舞台 + 数字人 |
| `scene.start` | `{id, backingUrl, t0}` | 开播伴奏带 | 舞台（播 `<audio>`） |
| `scene.tick` | `{t}` | 心跳 ~10Hz | 舞台（仅纠偏） |
| `scene.end` | `{id}` | 唱完 | 舞台（进 outro） |
| `tts.start/end` | `{seq, voice}` | 对白段起止 | 舞台 |
| `tts.audio` | `{seq, mime, b64}` | 对白音频分片 | 舞台 |
| `viseme.frame` | `{t, params:{ParamMouthOpenY,...}}` | **对白期实时口型帧** | 数字人 |
| `action.set` | `{name, loop, blend, dur}` | 设动作/表情 | 数字人 |
| `subtitle` | `{speaker:"Angela"\|"Neo"\|"TeammateC", text}` | 对白字幕 | 舞台 |
| `error` | `{code, message}` | 错误 | 舞台 |

> **合唱期不下发 `viseme.frame`/`action.set`**：走 `scene.tracks` 预烘焙轨道，由前端音频时钟驱动。
> **对白期（intro/outro）才实时推**。

## 3. 关键流程示例

### 3.1 加载场1（传奇）+ 切到 Angela + 开场对白
```jsonc
// stage → backend
{ "type": "scene.load", "seq": 1, "data": { "id": "chuanqi" } }

// backend → stage / 数字人
{ "type": "scene.loaded", "seq": 2, "data": { "id": "chuanqi", "title": "传奇",
  "character": "angela", "manifest": { /* 见 03 scene.json */ } } }
{ "type": "character.set", "seq": 3, "data": { "name": "angela", "model": "models/angela/angela.model3.json" } }

// 开场对白（实时 TTS + 口型）
{ "type": "subtitle", "seq": 4, "data": { "speaker": "Angela", "text": "这首《传奇》，我们一起唱吧。" } }
{ "type": "action.set", "seq": 5, "data": { "name": "talk", "loop": true } }
{ "type": "tts.start", "seq": 6, "data": { "seq": 1, "voice": "angela" } }
{ "type": "viseme.frame", "seq": 7, "ts": 0.1, "data": { "params": { "ParamMouthOpenY": 0.6 } } }
// ... tts.audio / viseme.frame ...
{ "type": "tts.end", "seq": 99, "data": { "seq": 1 } }
```

### 3.2 进入合唱（传奇）
```jsonc
{ "type": "scene.start", "seq": 20, "data": { "id": "chuanqi" } }

{ "type": "scene.tracks", "seq": 21, "data": {
    "lyrics":  { "url": "/assets/演示用例/传奇_分轨/lyrics.json" },
    "visemes": { "url": "/assets/演示用例/传奇_分轨/visemes.json" },
    "actions": { "url": "/assets/演示用例/传奇_分轨/actions.json" } } }

{ "type": "action.set", "seq": 22, "data": { "name": "singing_high", "loop": true } }   // Angela
{ "type": "scene.start", "seq": 23, "data": { "id": "chuanqi",
    "backingUrl": "/assets/演示用例/传奇_分轨/传奇_backing.wav", "t0": 0 } }

{ "type": "scene.tick", "seq": 24, "ts": 12.4, "data": { "t": 12.4 } }   // 心跳
// ... 队友C 在现场对着同一伴奏带真唱（齐唱），麦走 PA，不经本协议 ...
{ "type": "scene.end", "seq": 200, "data": { "id": "chuanqi" } }
```

### 3.3 收尾 → 切场2（因为爱情 → Neo）
```jsonc
{ "type": "outro.start", "seq": 201, "data": { "id": "chuanqi" } }   // 传奇收尾 TTS
// 收尾完 →
{ "type": "scene.load", "seq": 300, "data": { "id": "yinwei-aiqing" } }
{ "type": "character.set", "seq": 301, "data": { "name": "neo", "model": "models/neo/neo.model3.json" } }
// 因为爱情：伴奏带含 Neo 男声(RVC)；队友C 现场唱女声部（多声部对唱）
{ "type": "scene.start", "seq": 320, "data": { "id": "yinwei-aiqing",
    "backingUrl": "/assets/演示用例/因为爱情_分轨/因为爱情_backing.wav" } }
```

## 4. REST 细节

### `GET /api/scenes`
```json
[ { "id": "chuanqi", "title": "传奇", "character": "angela",
    "relation": "unison", "duration": 280.0, "cover": "/assets/.../传奇cover.jpg" },
  { "id": "yinwei-aiqing", "title": "因为爱情", "character": "neo",
    "relation": "duet", "duration": 272.0, "cover": "/assets/.../因为爱情cover.jpg" } ]
```

### `GET /api/scenes/{id}`
返回 `scene.json`（字段见 `03`），并把相对路径补成 URL。

### `POST /api/tts`
`{text, voice}` → `audio/wav`。

## 5. 主时钟与同步模型（必读）

| 阶段 | 时间权威 | 口型 | 动作 |
|------|----------|------|------|
| `singing` | 前端 `<audio>.currentTime`（**伴奏带**） | `visemes.json` 插值 | `actions.json` 查段 |
| `intro`/`outro` | TTS 音频时间 | 后端实时推 `viseme.frame` | 后端 `action.set` |

```js
function frame(){
  const t = audioEl.currentTime;          // ★ 权威（伴奏带）
  lyricsView.update(t);
  character.setViseme(visemes.lookup(t));
  const seg = actions.at(t);
  if (seg && seg !== curAction){ character.playMotion(seg.action, seg); curAction = seg; }
  requestAnimationFrame(frame);
}
```

**观众/队友C 同步**：伴奏带同一文件，一路给舞台 `<audio>`、一路给调音台 lineout → 队友C 返听。
队友C 听到的与屏幕口型同源；队友C **不跟屏幕延迟**，跟返听。

## 6. 错误码

| code | 含义 | 建议 |
|------|------|------|
| `SCENE_NOT_FOUND` | 场 id 不存在 | 回到场选择 |
| `TRACKS_MISSING` | 轨道缺失 | 用 mock 轨道兜底 |
| `CHARACTER_LOAD_FAIL` | 数字人模型加载失败 | 静态立绘兜底（见 `08`） |
| `TTS_FAILED` | TTS 出错 | 走预录对白 |
| `WS_PROTOCOL` | 信封/字段不合法 | 打日志忽略 |

## 7. 连接管理

- 启动即连 `/ws`；断线 1/2/4s 退避重连，重连后重发 `hello` + 重载当前场。
- 后端每连接维护状态机：`idle → scene_loaded → singing → outro`。
- 单用户演示，不考虑并发。

## 8. 版本

- 协议 `v0.2`（`hello.data.proto="0.2"`）：相比 v0.1 引入 **scene / character**，原 song 概念并入 scene。
- 字段加可选不算破坏；改语义/删字段需升版本号 + 全队同步。

→ 数据字段见 `03`；烤声见 `09`；联调见 `08`。
