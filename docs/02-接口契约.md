# 02 · 接口契约（★ 三方对齐的唯一真源）

> **这是全队最重要的一篇。** 任何跨模块的数据形状都在这里冻结。字段名、单位、枚举值三方**必须**完全一致。
> 改这里 = 全队停一下同步。`data/samples/` 里的 JSON 是本契约的可执行样例。

---

## 0. 端点总览

| 通道 | 地址 | 用途 |
|------|------|------|
| REST | `GET /api/songs` | 歌曲列表（选歌 UI） |
| REST | `GET /api/songs/{id}` | 单曲 manifest（指向 mix.wav / 各轨道文件） |
| REST | `GET /assets/{path}` | 静态资源（mix.wav、MV、模型、轨道 json） |
| REST | `POST /api/tts` | 一次性 TTS：`{text, voice}` → audio/wav（可选，同步用） |
| WS | `ws://host/ws` | 实时通道：控制 / 事件 / TTS / 口型帧 |

## 1. WebSocket 消息信封

所有 WS 消息统一信封（**双方收发都用它**）：

```json
{ "type": "<MessageType>", "seq": 0, "ts": 0.0, "data": { ... } }
```

- `type`：消息类型（见下表）
- `seq`：单调递增整数，便于乱序检测/去重（同一会话内）
- `ts`：秒。合唱期 = 相对 `mix.wav` 起点的时间；对白期 = 相对该 TTS 段起点的时间；事件类可为 0
- `data`：负载，结构由 `type` 决定

## 2. 消息类型总表

### 2.1 前端 → 后端（控制）

| type | data | 何时发 | 后端动作 |
|------|------|--------|----------|
| `hello` | `{role:"stage", caps:["tts","viseme"]}` | 连接后 | 回 `hello` |
| `song.select` | `{id:"daoxiang"}` | 用户选歌 | 加载 manifest，回 `song.loaded`；触发选歌 TTS |
| `song.start` | `{id:"daoxiang"}` | 进入合唱 | 下发 `song.tracks` + `song.start` |
| `song.stop` | `{}` | 中途停 | 回 `song.end`，状态回到 select |
| `finale.start` | `{}` | 唱完 | 触发收尾 TTS |
| `tts.request` | `{text:"..."}` | （可选）临时要 TTS | 生成并推 `tts.*` |

### 2.2 后端 → 前端（事件 / 数据 / 流）

| type | data | 含义 | 消费方 |
|------|------|------|--------|
| `hello` | `{role:"backend", songs:[...]}` | 握手 + 歌单 | 舞台 |
| `phase.change` | `{phase:"select"\|"singing"\|"finale"}` | 幕切换 | 舞台（状态机）/ 数字人 |
| `song.loaded` | `{id, title, manifest}` | 选歌完成，给 manifest | 舞台 |
| `song.tracks` | `{lyrics, visemes, actions}`（内联或 `{url}`） | **合唱期一次性下发三条轨道** | 舞台 + 数字人 |
| `song.start` | `{id, mixUrl, t0}` | 开始放 mix | 舞台（播 `<audio>`） |
| `song.tick` | `{t}` | 心跳（~10Hz） | 舞台（仅纠偏/状态） |
| `song.end` | `{id}` | 唱完 | 舞台（进 finale） |
| `tts.start` | `{seq, text, voice}` | 一段对白开始 | 舞台 |
| `tts.audio` | `{seq, mime:"audio/wav", b64:"..."}` | 分片音频 | 舞台（拼播） |
| `tts.end` | `{seq}` | 对白结束 | 舞台 |
| `viseme.frame` | `{t, params:{ParamMouthOpenY:0.6, ParamMouthForm:0.2}}` | **对白期实时口型帧** | 数字人 |
| `action.set` | `{name:"talk"\|"wave"\|..., loop, blend, dur}` | 设置动作/表情 | 数字人 |
| `subtitle` | `{speaker:"Angela"\|"Neo", text}` | 对白字幕 | 舞台 |
| `error` | `{code, message}` | 错误 | 舞台 |

> **合唱期不下发 `viseme.frame`/`action.set`**：口型动作走 `song.tracks` 的预烘焙轨道，由前端音频时钟驱动。
> **对白期（幕一/三）才实时推** `viseme.frame` + `action.set`（此时没有预烘焙轨道）。

## 3. 关键消息示例

### 3.1 选歌 → 加载 → 选歌对白
```jsonc
// stage → backend
{ "type": "song.select", "seq": 3, "ts": 0, "data": { "id": "daoxiang" } }

// backend → stage
{ "type": "phase.change", "seq": 4, "data": { "phase": "select" } }
{ "type": "song.loaded",  "seq": 5, "data": { "id": "daoxiang",
  "title": "稻香", "manifest": { /* 见 03 song.json */ } } }

// backend → 数字人/舞台：选歌对白（实时 TTS + 口型）
{ "type": "action.set",  "seq": 6, "data": { "name": "talk", "loop": true } }
{ "type": "subtitle",    "seq": 7, "data": { "speaker": "Angela", "text": "就让我们一起唱《稻香》吧！记得跟着我的高声部哦。" } }
{ "type": "tts.start",   "seq": 8, "data": { "seq": 1, "voice": "angela" } }
{ "type": "viseme.frame","seq": 9, "ts": 0.00, "data": { "params": { "ParamMouthOpenY": 0.0 } } }
{ "type": "viseme.frame","seq":10, "ts": 0.12, "data": { "params": { "ParamMouthOpenY": 0.6, "ParamMouthForm": 0.2 } } }
{ "type": "tts.audio",   "seq":11, "data": { "seq": 1, "mime": "audio/wav", "b64": "<chunk>" } }
{ "type": "tts.end",     "seq":12, "data": { "seq": 1 } }
```

### 3.2 进入合唱
```jsonc
// stage → backend
{ "type": "song.start", "seq": 20, "data": { "id": "daoxiang" } }

// backend → stage（一次性下发三条轨道；也可只给 url 让前端按需拉）
{ "type": "song.tracks", "seq": 21, "data": {
    "lyrics":  { "url": "/assets/songs/daoxiang/lyrics.json" },
    "visemes": { "url": "/assets/songs/daoxiang/visemes.json" },
    "actions": { "url": "/assets/songs/daoxiang/actions.json" } } }

// backend → 数字人：切到合唱高声部动作
{ "type": "action.set", "seq": 22, "data": { "name": "singing_high", "loop": true } }

// backend → stage：开播
{ "type": "song.start", "seq": 23, "data": { "id": "daoxiang",
    "mixUrl": "/assets/songs/daoxiang/mix.wav", "t0": 0 } }

// 合唱中：心跳（前端用它做"是否落后/超前"提示，不逐帧渲染）
{ "type": "song.tick", "seq": 24, "ts": 12.40, "data": { "t": 12.40 } }

// 唱完
{ "type": "song.end", "seq": 200, "data": { "id": "daoxiang" } }
```

### 3.3 收尾
```jsonc
{ "type": "phase.change", "seq": 201, "data": { "phase": "finale" } }
{ "type": "action.set",   "seq": 202, "data": { "name": "wave", "loop": false, "dur": 3.0 } }
{ "type": "subtitle",     "seq": 203, "data": { "speaker": "Angela", "text": "今天唱得真不错呢，下次再一起练好不好？" } }
// ... tts.* / viseme.frame 实时推 ...
```

## 4. REST 细节

### `GET /api/songs`
```json
[ { "id": "daoxiang", "title": "稻香", "artist": "周杰伦",
    "duration": 223.0, "duet": true, "cover": "/assets/songs/daoxiang/cover.jpg" } ]
```

### `GET /api/songs/{id}`
返回 `song.json` manifest 全文（字段见 `03-数据格式规范.md`），并补上所有资源的最终 URL。

### `POST /api/tts`（可选，给非 WS 场景兜底）
- 请求：`{ "text": "...", "voice": "angela" }`
- 响应：`audio/wav` 二进制（或 `{ "url": "/assets/tts/xxx.wav" }`）

## 5. 主时钟与同步模型（必读）

| 阶段 | 时间权威 | 口型如何驱动 | 动作如何驱动 |
|------|----------|--------------|--------------|
| `singing` | 前端 `<audio>.currentTime`（**渲染权威**） | 前端在 `visemes.json` 按 `t` 插值 → `character.setViseme()` | 前端在 `actions.json` 查段 → `character.playMotion()` |
| `select`/`finale` | TTS 音频播放时间 | 后端实时推 `viseme.frame` → 前端转给 `character.setViseme()` | 后端推 `action.set` |

**前端伪代码（合唱期，主循环）：**
```js
function frame() {
  const t = audioEl.currentTime;             // ★ 权威时钟
  lyricsView.update(t);                       // 高亮 [t,t+d] 行
  const v = visemes.lookup(t);                // 插值
  character.setViseme(v);                     // ParamMouthOpenY/Form
  const act = actions.at(t);
  if (act && act !== currentAction) { character.playMotion(act.name, act); currentAction = act; }
  requestAnimationFrame(frame);
}
```

**心跳纠偏（合唱期）：** 收到 `song.tick{t}` 时，若 `|t - audioEl.currentTime| > 0.3s`，给 UI 一个"不同步"提示；一般不强制 seek（seek 会跳）。`t0` 为歌曲起点对齐用。

## 6. 错误码

| code | 含义 | 建议 |
|------|------|------|
| `SONG_NOT_FOUND` | 歌曲 id 不存在 | 回到 select |
| `TRACKS_MISSING` | 轨道文件缺失 | 用 mock 轨道兜底 |
| `TTS_FAILED` | TTS 出错 | 走预录对白兜底 |
| `WS_PROTOCOL` | 信封/字段不合法 | 打日志，忽略 |

## 7. 连接管理

- 前端启动即连 `/ws`；断线 1s/2s/4s 指数退避重连，重连后重新 `hello`。
- 后端每条连接维护一个会话状态机（`select → singing → finale`）。
- 演示单用户，不考虑并发；多用户后续再加 `session_id`。

## 8. 版本

- 协议版本：`v0.1`（握手时 `hello.data.proto="0.1"`）。本版锁定，不再轻易改。
- 字段加新**可选**字段不算破坏；改语义/删字段需升版本号 + 全队同步。

→ 数据字段细节见 `03-数据格式规范.md`；时间线见 `01`。
