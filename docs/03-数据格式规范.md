# 03 · 数据格式规范（路演版）

> 落盘 / 走 WS 的数据结构。`data/samples/` 是可运行样例，字段以本文为准。
> 单位：时间**秒**，帧率默认 **30**，权重 **0.0–1.0**。
> 路演版核心：以 **scene（场）** 为单位；新增 **character**；歌词声部含 `digital`（数字人）/`teammateC`（现场）。

---

## 1. `scene.json` — 单场清单（manifest）

`GET /api/scenes/{id}` 返回它的内容（路径补成 URL）。

```jsonc
{
  "id": "yinwei-aiqing",
  "title": "因为爱情",
  "artist": "陈奕迅 / 王菲",
  "character": "neo",                 // 该场数字人：angela | neo
  "relation": "duet",                 // unison(齐唱) | duet(多声部对唱)
  "duration": 272.0,
  "parts": {
    "digital":    { "performer": "Neo(数字人)",   "voice": "陈奕迅男声部" },
    "teammateC":  { "performer": "队友C(现场真唱)", "voice": "王菲女声部" }
  },
  "audio": {
    "backing":     "演示用例/因为爱情_分轨/因为爱情_backing.wav",   // ★伴奏带(含数字人声)
    "instrumental":"演示用例/因为爱情_分轨/因为爱情 男声_instrumental.wav",
    "vocal_src":   "演示用例/因为爱情_分轨/因为爱情 男声_vocals.wav", // 数字人源人声(男声)
    "vocal_rvc":   "演示用例/因为爱情_分轨/因为爱情 男声_vocals_neo_rvc.wav" // RVC后(口型源)
  },
  "tracks": {
    "lyrics":  "演示用例/因为爱情_分轨/lyrics.json",
    "visemes": "演示用例/因为爱情_分轨/visemes.json",
    "actions": "演示用例/因为爱情_分轨/actions.json"
  },
  "mv": "演示用例/因为爱情.mp4",
  "cover": "演示用例/因为爱情cover.jpg",
  "dialogue": {
    "intro":  ["因为爱情，不会轻易悲伤。我们一起，好吗？"],
    "outro":  ["唱得真好，这就是爱情的样子吧。"]
  }
}
```

传奇场对照（`id:"chuanqi"`, `character:"angela"`, `relation:"unison"`）：`vocal_src`=传奇整曲人声，`parts.digital`=Angela 唱旋律、`parts.teammateC`=队友C 唱**同一旋律**（齐唱）。

| 字段 | 必填 | 说明 |
|------|------|------|
| `character` | ✅ | 该场用哪个数字人（前端据此 `character.set` 切模型） |
| `relation` | ✅ | unison / duet；前端据渲染歌词双栏 |
| `audio.backing` | ✅ | **伴奏带**：伴奏 + 数字人RVC人声。队友C 唱的部分**不在带里** |
| `audio.vocal_rvc` | ✅ | RVC 后的数字人声 = **口型数据源** |
| `parts` | ✅ | `digital`/`teammateC` 两声部说明；`teammateC` 仅显示用，不进伴奏带 |
| `dialogue.*` | ⬜ | intro/outro 文本，后端 TTS |

## 2. `lyrics.json` — 分声部歌词时间轴

扁平 `lines`。**以 `performer` + `text` 为准**（`part` 字段为兜底/兼容旧逻辑）：

- **栏位由 `performer` 决定**：`Neo`/`Angela` → 数字人栏，`队友C`/`You` → 队友栏，`Neo+队友C`（含多人）→ **两栏同显**。
- **单句复合**：`text` 内用内联标记 `（Neo）`/`(Neo)`/`（合唱）`/`(You)` 标出一句里多人各唱的段落；前端剥掉标记、按段着色。

```jsonc
{
  "scene": "yinwei-aiqing", "fps": 30,
  "lines": [
    { "t": 11.74, "d": 2.78, "performer": "Neo",       "text": "给你一张过去的CD" },
    { "t": 16.30, "d": 2.78, "performer": "队友C",     "text": "听听那时我们的爱情" },
    { "t": 37.69, "d": 2.78, "performer": "队友C",     "text": "听到都会红着脸躲避" },
    { "t": 53.79, "d": 3.22, "performer": "Neo+队友C", "text": "因为爱情 不会轻易悲伤" },
    { "t": 92.53, "d": 3.88, "performer": "Neo+队友C", "text": "（Neo）依然还有人在那里游荡 （合唱）人来人往" }
  ]
}
```

| performer | 进哪个栏 | 着色 |
|-----------|----------|------|
| `Neo` / `Angela` | 数字人 | 蓝（digital） |
| `队友C` / `You` | 队友C 现场 | 金（teammate） |
| `Neo+队友C`（多人） | 两栏同显 | 紫（duet）；`text` 内标记按段着色 |

- **传奇（unison）**：每行 `performer:"Angela+队友C"`，两栏同显（齐唱）。
- **因为爱情（duet）**：按现场分工标 `performer`；合唱/对唱句用 `Neo+队友C`。
- **单句复合**：`performer` 多人 + `text` 内 `（谁）` 标记 → 一行多人分段着色（如上 92.53）。
- 高亮：`[t, t+d]` 包含 `audio.currentTime` 的行；队友C 栏高亮 = 提示队友C该唱。

> 时间戳必须以**伴奏带**为准打点（见 `07`）。`part` 字段保留兼容，新数据一律以 `performer` 为准。

## 3. `visemes.json` — 口型轨道（合唱期预烘焙）

对**数字人 RVC 人声**（`vocal_rvc`）逐帧采样。

```jsonc
{
  "scene": "yinwei-aiqing", "fps": 30, "params": ["ParamMouthOpenY"], "start": 0.0,
  "frames": [ [0.0], [0.05], [0.6], [0.7] /* ... duration*fps 行 ... */ ]
}
```
- `frames[i]` 第 j 列对应 `params[j]`，时间 = `start + i/fps`。
- 生成：librosa RMS@30fps → 归一化到 0..1（按 0.95 分位）→ 三帧平滑（见 `04 §6`）。
- 传奇用 Angela 人声；因为爱情用 Neo 人声。**只烘焙数字人声部**（队友C 不对口型，是真人）。

## 4. `actions.json` — 动作轨道（合唱期预烘焙）

```jsonc
{
  "scene": "yinwei-aiqing",
  "timeline": [
    { "t": 0.0,  "action": "idle",         "loop": true },
    { "t": 17.5, "action": "singing_low",  "loop": true },   // Neo 男声部
    { "t": 90.0, "action": "sway",         "loop": true },
    { "t": 260,  "action": "bow",          "loop": false, "blend": 0.4, "dur": 4.0, "then": "idle" }
  ]
}
```

动作词表（= Live2D motion 组名，队友 A 提供同名 motion，见 `05 §4`）：

| name | 必备 | 说明 |
|------|------|------|
| `idle` | ✅ | 待机 |
| `talk` | ✅ | 对白（intro/outro） |
| `singing_high` | ✅ | 唱高声部/女声（Angela 用） |
| `singing_low` | ✅ | 唱低声部/男声（Neo 用） |
| `sway` `wave` `bow` `point` | ⬜ | 摇摆/挥手/鞠躬/指向 |

> 传奇 Angela 用 `singing_high`；因为爱情 Neo 用 `singing_low`。对白期动作由后端 `action.set` 实时下。

## 5. `character.json` — 数字人清单（队友 A + B 共建）

```jsonc
{
  "angela": {
    "model": "models/angela/angela.model3.json",
    "gender": "female",
    "voice": { "engine": "rvc", "model": "voice/models/angela_female.pth",
               "index": "voice/models/angela_female.index", "pitch_shift": 0, "f0": "rmvpe" }
  },
  "neo": {
    "model": "models/neo/neo.model3.json",
    "gender": "male",
    "voice": { "engine": "rvc", "model": "voice/models/neo_male.pth",
               "index": "voice/models/neo_male.index", "pitch_shift": 0, "f0": "rmvpe" }
  }
}
```
- `voice.*` 仅后端烤声用（见 `09`）；前端只用 `model`。
- 模型/音色模型都是**大文件**，`.gitignore` 排除，本地/网盘同步。

## 6. TTS / 对白口型（运行时，非文件）

intro/outro 不落盘轨道，后端实时推（见 `02 §2.2`）。`viseme.frame.data.params` 同 §3。
音色统一：edge-tts 出声后可选过 RVC（Angela/Neo 模型）让对白音色与唱歌一致。

## 7. 命名与路径约定

- 资产根：`演示用例/`（路演版主目录）+ `assets/`（兼容）。URL 前缀 `/assets/`。
- 单曲分轨目录：`演示用例/<曲名>_分轨/`（与现有 `因为爱情_分轨/` 一致；传奇建 `传奇_分轨/`）。
- 伴奏带命名：`<曲名>_backing.wav`；RVC 人声：`<源名>_<角色>_rvc.wav`。
- 时间精度两位小数（10ms）；JSON `UTF-8`；音频 `wav` 16/24-bit PCM。

→ 后端如何产出见 `04`；烤声细节见 `09`；数字人消费见 `05`。
