## 3. 编排状态机

```
        ┌──────── select ────────┐
        │  (Angela 问→用户选歌)    │
        ▼ song.loaded + 对白结束  │
      singing ──song.end──► finale ──(可选)──► select
      (MV+歌词+口型)            (Angela 收尾)
```

`orchestrator.js` 骨架：
```js
const phase = { cur:'select' };
ws.on('phase.change', d => setPhase(d.phase));
ws.on('song.loaded',  d => { song = d; showSelected(d); });
ws.on('song.start',   d => startSinging(d));      // §4
ws.on('song.end',     () => ws.send('finale.start', {}));
ws.on('song.tick',    d => clock.notify(d.t));    // 纠偏提示
ws.on('tts.start/end', ...);
ws.on('viseme.frame', d => angela.setViseme(d.params));   // 仅对白期到达
ws.on('action.set',   d => angela.playMotion(d.name, d));
ws.on('subtitle',     d => subtitle.show(d));

function userPicks(id){ ws.send('song.select', {id}); }
function startSinging({id, mixUrl, t0}){
  setPhase('singing');
  audio.src = mixUrl; audio.play();
  clock.attach(audio);                              // §4 主时钟
  lyrics.mount(song.tracks.lyricsUrl);
  clock.loadTracks(song.tracks);                    // 拉 visemes/actions
  angela.playMotion('singing_high', {loop:true});
  loop();                                           // §4 主循环
}
```

## 4. 主时钟与主循环（合唱期，渲染权威）

```js
// clock.js
const clock = {
  audio:null, vis:null, act:null, curAction:null,
  attach(a){ this.audio=a; },
  async loadTracks({visemes,actions}){
    this.vis  = await fetch(visemes.url||visemes).then(r=>r.json());
    this.act  = await fetch(actions.url||actions).then(r=>r.json());
  },
  // 在 visemes.frames 里按 t 插值
  visemeAt(t){ /* fps/start + 线性插值，返回 {ParamMouthOpenY, ...} */ },
  actionAt(t){ /* 在 act.timeline 里找 <=t 的最后一段 */ },
  notify(serverT){ /* 若 |serverT-audio.currentTime|>0.3 显示不同步提示 */ }
};

function loop(){
  if(phase.cur!=='singing') return;
  const t = audio.currentTime;                       // ★ 权威
  lyrics.update(t);
  angela.setViseme(clock.visemeAt(t));
  const seg = clock.actionAt(t);
  if(seg && seg!==clock.curAction){ angela.playMotion(seg.action, seg); clock.curAction=seg; }
  requestAnimationFrame(loop);
}
```
- **只读 `audio.currentTime`，不靠 WS 逐帧。** 见 `00 §4`、`02 §5`。
- 歌词高亮：定位 `[t,t+d]` 包含 `t` 的行；可加逐行淡入。
- `duet` 行两栏都高亮。

## 5. 歌词双栏（lyrics.js）

- 拉 `lyrics.json`，按 `part` 分成高/低两列渲染。
- `update(t)`：清除上一次高亮，点亮当前行，滚动让当前行居中。
- 进度：行内可画一个细进度条 = `(t-line.t)/line.d`。
- 字幕（对白期）单独组件，`subtitle.show({speaker,text})`。

## 6. 接数字人（character-client.js）

```js
import { Character } from '../character/character.js';
const angela = await Character.mount(document.getElementById('cv'),
                                     { model:'../character/models/angela/angela.model3.json' });
angela.idle();
// 暴露给 orchestrator：angela 即可（setViseme/playMotion...）
window.angela = angela;
```
- 路径同源问题：开发时把 `stage` 和 `character` 放同一静态服务下（或后端 `/assets` 托管两者）。
- 数字人加载失败兜底：`catch` 后显示静态立绘 `angela.png`，并让 `setViseme` 变 no-op（流程不中断）。

## 7. WS 客户端（ws-client.js）

- 信封：`send(type,data)` 自动填 `seq`（自增）+ `ts`。
- 重连：1/2/4s 退避；重连后重发 `hello`，并按需重发当前 phase。
- 收消息按 `type` 派发（事件总线 / 简单 `on(type,fn)`）。

## 8. 离线/兜底模式

- 后端 `/ws` 连不上 → 进入 `OFFLINE`：
  - 直接 `fetch('/assets/songs/daoxiang/song.json')`，本地播 `mix.wav`，本地拉 `lyrics/visemes/actions`。
  - 对白用**预录 wav**（B 提前生成放 assets）替代 TTS；字幕照常。
- MV 缺失 → 用一张歌词背景图或 `<canvas>` 频谱可视化（可选，见 `08`）。
- 这样即使后端当场挂掉，demo 仍能走完。
