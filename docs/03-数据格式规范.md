# 03 · 数据格式规范

> 所有"落在磁盘 / 走 WS"的数据结构。`data/samples/` 是可运行的样例，字段以本文为准。
> 单位统一：时间**秒**，帧率 `fps` 默认 **30**，音量/权重 **0.0–1.0**。

---

## 1. `song.json` — 单曲清单（manifest）

后端 `/api/songs/{id}` 返回它的内容（并把相对路径补成 URL）。

```jsonc
{
  "id": "daoxiang",
  "title": "稻香",
  "artist": "周杰伦",
  "duration": 223.0,
  "bpm": 92,
  "duet": true,
  "parts": {
    "high": { "speaker": "Angela", "label": "高声部" },
    "low":  { "speaker": "Neo",    "label": "低声部" }
  },
  "audio": {
    "mix":          "songs/daoxiang/mix.wav",          // 成片（合唱期 <audio> 播这个）
    "instrumental": "songs/daoxiang/instrumental.wav", // 伴奏（混音源，可不对外）
    "vocals_neo":   "songs/daoxiang/vocals_neo.wav",   // 低声部人声（Neo）
    "vocals_angela":"songs/daoxiang/vocals_angela_rvc.wav" // 高声部人声（Angela，已 RVC）★口型源
  },
  "tracks": {
    "lyrics":  "songs/daoxiang/lyrics.json",
    "visemes": "songs/daoxiang/visemes.json",
    "actions": "songs/daoxiang/actions.json"
  },
  "mv": "songs/daoxiang/mv.mp4",
  "cover": "songs/daoxiang/cover.jpg",
  "dialogue": {
    "intro":    "今天，你想唱什么歌呢？",                     // 选歌页 Angela 开场
    "selected": ["就让我们一起来唱《稻香》吧！", "记得跟着我的高声部哦。"],
    "finale":   ["今天唱得真不错呢，下次我们再一起练好不好？"]
  },
  "voices": {
    "angela": { "rvc_model": "angela_v1.pth", "pitch_shift": 12, "f0_method": "rmvpe" }
  }
}
```

字段说明：

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | ✅ | 全局唯一，小写拼音 |
| `parts` | ✅ | `high`=Angela、`low`=Neo；前端据此分两栏着色 |
| `audio.mix` | ✅ | 合唱期唯一播放源；必须与 `vocals_angela`、`lyrics/visemes/actions` 时间轴**完全对齐** |
| `audio.vocals_angela` | ✅ | 口型数据源（算 visemes 用） |
| `tracks.*` | ✅ | 三条时间轴，见下 |
| `dialogue.*` | ⬜ | 选歌/收尾对白文本；后端拿去 TTS（也可写死在后端） |
| `voices.angela` | ⬜ | RVC 参数；纯后端用，前端忽略 |

## 2. `lyrics.json` — 分声部歌词时间轴

**核心：一个扁平的 `lines` 数组**，每行带 `part`。前端按 `part` 分到高/低两栏，按 `t` 高亮。

```jsonc
{
  "song": "daoxiang",
  "fps": 30,
  "lines": [
    { "t": 12.40, "d": 4.10, "part": "high", "speaker": "Angela", "text": "对这个世界如果你有太多的抱怨" },
    { "t": 12.40, "d": 4.10, "part": "low",  "speaker": "Neo",    "text": "对这个世界如果你有太多的抱怨" },
    { "t": 16.70, "d": 3.80, "part": "high", "speaker": "Angela", "text": "跌倒了就不敢继续往前走" },
    { "t": 16.70, "d": 3.80, "part": "low",  "speaker": "Neo",    "text": "跌倒了就不敢继续往前走" },
    { "t": 20.80, "d": 3.60, "part": "duet", "speaker": "Angela+Neo", "text": "为什么人要这么的脆弱 堕落" }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `t` | 行起点（秒，相对 mix 起点） |
| `d` | 持续时长（秒） |
| `part` | `high` / `low` / `duet`（两人同句）。`duet` 时两栏都显示同句 |
| `text` | 歌词文本（中文） |

**高亮规则（前端）：** 当前行 = `[t, t+d]` 包含 `audio.currentTime` 的行；进阶可在词内做逐字进度（本版按行即可）。

## 3. `visemes.json` — 口型轨道（合唱期预烘焙）

对 Angela 高声部人声逐帧采样。**Live2D 关心两个参数**：`ParamMouthOpenY`（张嘴，必需）、`ParamMouthForm`（嘴角，可选，可固定）。

**紧凑帧格式（推荐，省体积）：**
```jsonc
{
  "song": "daoxiang",
  "fps": 30,
  "params": ["ParamMouthOpenY", "ParamMouthForm"],
  "start": 0.0,
  "frames": [
    [0.00, 0.00],
    [0.18, 0.05],
    [0.62, 0.30],
    [0.71, 0.28]
    // ... 共 duration*fps 行
  ]
}
```
- `frames[i]` 第 j 列对应 `params[j]`，第 i 帧时间 = `start + i/fps`。
- 只放 `ParamMouthOpenY` 一列也合法（`params:["ParamMouthOpenY"]`）。

**生成方法（队友 B）：**
```python
# 伪代码：librosa 算 RMS → 映射到 0..1 → 平滑
import librosa, numpy as np
y, sr = librosa.load("vocals_angela_rvc.wav", sr=22050, mono=True)
rms = librosa.feature.rms(y=y, frame_length=512, hop_length=sr//30)[0]  # 30fps
openY = np.clip(rms / np.quantile(rms, 0.95), 0, 1)        # 归一化到 0..1
openY = smooth(openY, window=3)                            # 轻微平滑去抖
# 可选：用 forced-alignment 得音素 → 估 ParamMouthForm（本版可省）
frames = [[round(float(o),3)] for o in openY]
```
> `ParamMouthOpenY` 典型范围 Live2D 里约 0–1；映射后可在数字人侧再调增益（见 `05 §3`）。

## 4. `actions.json` — 动作轨道（合唱期预烘焙）

把整首歌切成段，每段一个动作/表情。

```jsonc
{
  "song": "daoxiang",
  "timeline": [
    { "t": 0.00,  "action": "idle",         "loop": true },
    { "t": 11.50, "action": "singing_high", "loop": true },
    { "t": 60.20, "action": "sway",         "loop": true },
    { "t": 95.00, "action": "wave",         "loop": false, "blend": 0.4, "dur": 3.0, "then": "singing_high" },
    { "t": 210.0, "action": "bow",          "loop": false, "blend": 0.4, "dur": 4.0, "then": "idle" }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `t` | 段起点（秒） |
| `action` | 动作名，必须在 `动作词表` 内（见下） |
| `loop` | 是否循环 |
| `blend` | 过渡时长（秒，可选，默认 0.3） |
| `dur` | 非循环动作持续时长（可选） |
| `then` | 该动作结束后切到的动作（可选） |

**动作词表（动作名 = Live2D motion 组名，队友 A 提供同名 motion）：**

| name | 用途 | 必备 |
|------|------|------|
| `idle` | 待机呼吸 | ✅ |
| `talk` | 对白说话（幕一/三） | ✅ |
| `singing_high` | 唱高声部（带轻摆） | ✅ |
| `singing_low` | 唱低声部（备） | ⬜ |
| `sway` | 左右摇摆 | ⬜ |
| `wave` | 挥手 | ⬜ |
| `bow` | 鞠躬致意 | ⬜ |
| `point` | 指向（歌词/对方） | ⬜ |

> 对白期（幕一/三）动作由后端 `action.set` 实时下发（如 `talk`/`wave`），不走本文件。

## 5. TTS / 对白口型（运行时，非文件）

对白期不落盘轨道，后端实时推（见 `02 §2.2` 的 `tts.*` / `viseme.frame`）。
- `viseme.frame.data.params` 字段同上：`{ParamMouthOpenY, ParamMouthForm}`。
- 推送频率 ~30fps；前端转发给 `character.setViseme()`。
- 生成方式（队友 B）：edge-tts 流式音频 → 实时 RMS（或 WordBoundary 事件）→ 帧参数。详见 `04 §4`。

## 6. 命名与路径约定

- 资产根：`assets/`（.gitignore 排除）；URL 前缀 `/assets/`。
- 单曲目录：`assets/songs/{id}/`，里面放 `mix.wav`、`*.wav`、`mv.mp4`、`cover.jpg`、`lyrics.json`、`visemes.json`、`actions.json`、`song.json`。
- 时间戳精度：保留两位小数（10ms）足够。
- 编码：音频 `wav`（16/24-bit PCM）或 `mp3`；MV `mp4(H.264+AAC)`；JSON `UTF-8`。

→ 后端如何产出这些文件见 `04`；数字人如何消费见 `05`。
