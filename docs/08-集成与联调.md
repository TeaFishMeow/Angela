## 1. Drop-in 整合顺序（黄金路径）

| 步 | 拼什么 | 数据 | 通过标准 |
|----|--------|------|----------|
| D1 | stage 骨架 + mock_ws | `data/samples/*` | 两场状态机走完、Angela→Neo 切换、歌词随 tick 滚 |
| D2 | + character 多模型 | mock visemes | 两个模型都加载、右侧透明、能切、能动嘴 |
| D3 | + 真 MV 背景 | 静态图/真 mv | MV 最底层、数字人/歌词在之上 |
| D4 | + 真后端 TTS | 真 /ws | intro/outro 有声、口型/字幕同步 |
| D5 | + 真伴奏带 + 真轨道 | 两曲真数据 | 合唱嘴音同步、双声部歌词时机准、两场切换 |
| D6 | + RVC 烤声 | 队友 B 产出 | 数字人声是 Angela/Neo 音色 |

## 3. mock_ws.py 用法

`packages/backend/mock/mock_ws.py`（已更新为 scene 语义）：

```bash
cd packages/backend/mock
pip install websockets
python mock_ws.py            # ws://0.0.0.0:8765
```
- `hello`→`scene.list`（两场）；`scene.load`→`scene.loaded`+`character.set`(angela/neo)+假 intro；`scene.start`→`scene.tracks`(内联)+`scene.start`+`tick`→`scene.end`；可连走两场。
- 前端把地址指过来即可；切真后端只改地址。

## 4. 现场音频链路（关键，路演前务必调通）

```
舞台电脑 ─backing.wav 播放─┬─→ <audio>（驱动 MV/歌词/口型）
                          └─→ 调音台 CH1（lineout / USB out）
队友C 麦 ──────────────────→ 调音台 CH2
调音台 ──→ PA（观众） + 队友C 返听（backing+自己麦）
```
- **伴奏带必须双路**：① 给舞台 `<audio>`；② 给调音台。两路是**同一文件**。
- **队友C 返听**：调音台给队友C 一路 monitor = backing + 自己麦；**不要让队友C 跟屏幕**（屏幕有显示延迟）。
- 调音：backing 与队友C 麦的比例、混响、返听音量，联排时定。
- 数字人系统**完全不碰**队友C 麦与 PA。

## 6. 常见坑与解

| 现象 | 原因 | 解法 |
|------|------|------|
| 切场时数字人白屏/卡 | 模型未预载 | `preload` 两模型后再 `switchTo` |
| Neo 模型找不到 | 男 Live2D 少 | 用 VRM/3D 男模，或 PNG+口型兜底 |
| 嘴对不上声音 | 用了 WS tick 时钟 | 合唱期用 `audio.currentTime`（`06 §4`） |
| 队友C 跟不上/慢半拍 | 跟屏幕延迟 | 返听给 backing，**不跟屏幕** |
| 数字人声电音重 | RVC 调参/模型差 | 见 `09 §5/§6`，或原声兜底 |
| 现场听不到数字人声 | backing 没进调音台 | 确认 backing lineout 进 PA |
| 两场歌词串了 | 轨道未按 scene 隔离 | 每场独立 `scene.tracks`，切场时清旧轨道 |
| TTS 没声音 | 自动播放策略 | 首次交互后再播 |
| 模型 404 | 路径/同源 | 相对路径 + 同源托管 |
| 大屏掉帧 | MV 高清 + 两模型 | MV 1080p；非当前模型 `visible=false` |

## 7. 兜底预案（Plan B）

1. **后端挂**：前端 `OFFLINE`——本地播 `backing.wav` + 本地轨道 + 预录对白（`06 §8`）。
2. **RVC 不及/差**：用原人声进伴奏带跑通；或录+修音（`09 §8`）。
3. **Live2D 模型挂**：静态立绘 + 幅度驱动嘴（CSS/两图切换）。
4. **MV 没素材**：背景图 + 频谱 canvas。
5. **演示机崩**：**全程录像备份**，现场放录像。
6. **调音/返听故障**：伴奏带直接进 PA，队友C 戴入耳跟伴奏带。
7. **现场网络/WS 抖**：合唱期本就不依赖逐帧 WS；对白期降级预录。

## 8. 路演走场脚本（详见 演示用例/路演runbook.md）

```
开场：主持人/队友C 介绍 → 舞台起
场1 传奇：Angela 出场 → intro 对白 → 播 backing+MV、Angela 对口型(旋律)、队友C 现场齐唱
        → outro 对白
切场：character 切 Neo → MV 换因为爱情
场2 因为爱情：Neo intro → 播 backing+MV、Neo 对口型(男声部)、队友C 现场唱女声部(对唱)
        → outro 对白 → 致谢
```
- 计时：每场约 4-5 分钟（含对白）；可只放主歌+副歌片段控时。
- 全程录像备份。
