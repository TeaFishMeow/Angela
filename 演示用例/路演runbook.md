## 2. 现场流程

```
1. 开场（主持人/队友C 介绍，~30s）
2. 场1 传奇（~4-5min）
   - Angela 出场 → intro 对白
   - 播 backing+MV，Angela 对口型旋律，队友C 现场齐唱
   - outro 对白
3. 切场（character: Angela→Neo，MV 换因为爱情，~10s）
4. 场2 因为爱情（~4-5min）
   - Neo 出场 → intro 对白
   - 播 backing+MV，Neo 对口型男声部，队友C 现场唱女声部（对唱）
   - outro 对白 → 致谢
5. 收场（~15s）
```
- 总时长约 10–12 分钟；控时可每场只放主歌+副歌。
- **队友C 全程跟返听，不跟屏幕。**

## 3. 信号约定

| 信号 | 谁发 | 动作 |
|------|------|------|
| 点"开始场1" | 你（舞台） | `scene.load(chuanqi)` 自动走 intro→singing→outro |
| 点"下一场" | 你 | `next.scene` → 场2 |
| 紧急停 | 你 | `scene.stop`；或直接切录像 |
| 队友C 卡住 | 队友C 手势 | 你 `scene.stop` 重来或跳过 |

## 4. 兜底（出事照此办）

| 故障 | 立刻做 |
|------|--------|
| 后端/网络挂 | 前端自动 OFFLINE：本地播 backing + 轨道 + 预录对白（你提前确认能切） |
| 数字人模型挂 | 切静态立绘 + 幅度驱动嘴（队友A 备好） |
| RVC 声音差/没烤好 | 伴奏带换成原声版（提前备 `*_backing_original.wav`） |
| 伴奏带没进 PA | 检查 lineout；应急用另一路播放器直接喂 PA |
| 队友C 听不见返听 | 调音台加返听音量；应急入耳直连伴奏带 |
| 演示机崩 | **切录像**（全程录像备份），主持人圆场 |
| 现场超时 | 每场砍到主歌+副歌；跳过对白 |
