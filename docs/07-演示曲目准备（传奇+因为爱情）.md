## 2. 传奇：分轨（Demucs）

```bash
cd 演示用例
demucs -n htdemucs --two-stems vocals "传奇 MV.mp4" -o 传奇_分轨/
# → 传奇_分轨/htdemucs/传奇 MV/{vocals.wav, no_vocals.wav}
mv "传奇_分轨/htdemucs/传奇 MV/vocals.wav"     "传奇_分轨/传奇 vocals.wav"
mv "传奇_分轨/htdemucs/传奇 MV/no_vocals.wav"  "传奇_分轨/传奇 instrumental.wav"
```
- 残留多 → `htdemucs_ft` 或 UVR5 `MDX23C`。
- 听验 `传奇 instrumental.wav` 人声基本干净。

## 4. RVC 烤声（队友 B，详见 09）

```bash
# 传奇：人声 → Angela（女）
rvc infer -m voice/models/angela_female.pth -i "传奇_分轨/传奇 vocals.wav" \
          -o "传奇_分轨/传奇 vocals_angela_rvc.wav" -p 0 -f0 rmvpe -ir voice/models/angela_female.index

# 因为爱情：男声 → Neo（男）
rvc infer -m voice/models/neo_male.pth -i "因为爱情_分轨/因为爱情 男声_vocals.wav" \
          -o "因为爱情_分轨/因为爱情 男声_vocals_neo_rvc.wav" -p 0 -f0 rmvpe -ir voice/models/neo_male.index
```
- `-p`（pitch_shift）：同性别模型通常 0；以听感为准（`09 §调参`）。
- **务必听验**，电音重就换模型/调参（`09 §质量`）。

## 5. 预混 → 伴奏带（★ backing.wav）

```bash
# 传奇：伴奏 + Angela 人声（齐唱：队友C同旋律现场唱，不入带）
ffmpeg -y -i "传奇_分轨/传奇 instrumental.wav" -i "传奇_分轨/传奇 vocals_angela_rvc.wav" \
  -filter_complex "[0:a]volume=0.85[a];[1:a]volume=0.95[b];[a][b]amix=inputs=2:duration=longest[m]" \
  -map "[m]" -ac 2 -ar 44100 "传奇_分轨/传奇_backing.wav"

# 因为爱情：伴奏 + Neo 人声（女声队友C现场唱，不入带）
ffmpeg -y -i "因为爱情_分轨/因为爱情 男声_instrumental.wav" -i "因为爱情_分轨/因为爱情 男声_vocals_neo_rvc.wav" \
  -filter_complex "[0:a]volume=0.9[a];[1:a]volume=0.95,aresample=async=1[b];[a][b]amix=inputs=2:duration=longest[m]" \
  -map "[m]" -ac 2 -ar 44100 "因为爱情_分轨/因为爱情_backing.wav"
```
- **backing.wav = 伴奏 + 数字人声，不含队友C 唱的部分**。
- **双路输出**（舞台 `<audio>` + 调音台 lineout），见 `04 §5`。
- 同起点：backing / vocal_rvc / 轨道 JSON 都从同一 0 点。

## 7. 歌词打点（lyrics.json）

- 工具：Audacity 导入 `backing.wav`，逐句听打标签 → 转脚本（见下）。
- **传奇**：每句两条（`part:"digital"` Angela 与 `part:"teammateC"` 队友C，**同文本同时间**）或用 `duet`。
- **因为爱情**：按原唱男女交替标 `digital`(Neo)/`teammateC`(队友C)，合唱句 `duet`。

歌词片段（时间戳占位，以 backing 实测为准）：
```
传奇（齐唱）："只是因为在人群中多看了你一眼 / 再也没能忘掉你容颜 …"（两人同唱）
因为爱情（对唱）：Neo"给你一张过去的CD" / 队友C"听听那时我们的爱情" / 合"因为爱情 不会轻易悲伤"
```

标签转 lyrics.json（声部版）：
```python
# labels.txt: start \t end \t text；传奇用 duet，因为爱情按行指定 part
import json
lines=[]
for ln in open("labels.txt",encoding="utf-8"):
    s,e,t=ln.rstrip("\n").split("\t"); s,e=float(s),float(e)
    lines.append({"t":round(s,2),"d":round(e-s,2),"part":"duet","performer":"Angela+队友C","text":t})
lines.sort(key=lambda x:x["t"])
json.dump({"scene":"chuanqi","fps":30,"lines":lines},open("lyrics.json","w",encoding="utf-8"),ensure_ascii=False,indent=2)
```
