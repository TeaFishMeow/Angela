## 1. ⚠️ 合规与风险（先读）

> 你选了"由歌手训练出的社区模型"。**公开路演是 outward-facing 场景**，下列风险必须知情：

| 风险 | 说明 |
|------|------|
| **肖像权/声音权（人格权）** | 用某真实歌手音色的模型在公开场合"替他唱"，可能侵犯其声音权/表演者权，国内《民法典》对声音有保护 |
| **著作权** | 歌词、旋律、录音均有版权；公开表演需注意（路演通常属合理使用范畴，但商业/大场面另论） |
| **平台/模型授权** | 社区模型的 LICENSE 未必允许公开商用演示 |
| **声誉** | 观众若听出是某明星声音"被AI唱"，可能引发争议 |

**建议优先级（从最稳到最险）：**
1. ✅ **用自有/队友/声优的干净录音训练的模型**（自有版权，最稳）——但你选了不自训，可让队友B 用现成**通用女声/男声**（非特定明星）模型。
2. ✅ **明显虚构/合成音色**的角色模型（听不出是谁）。
3. ⚠️ **特定歌手音色模型**：仅限**内部/非公开**演示；**公开路演需取得授权或换音色**。
4. ❌ 不要在公开路演用明显克隆当红歌手的音色而不说明。

> 实操：**挑"听不出是某个具体明星"的优质角色模型**，或路演现场字幕标注"AI 合成声音"。把这条和主办方/导师确认一次再上台。

## 2. 选模型

**来源（社区）：**
- AI-Hub（HuggingFace `rakiment/...`、`RVC-Models/...` 等集合）
- weights.gg、voice-models 社区帖
- 国内：Applio/GPT-SoVITS 社区分享、B站/爱发电作者发布

**选择标准（务必）：**
- ✅ 有配套 `.index`（检索特征，音色更稳、更贴）
- ✅ 训练数据干净（无伴奏/噪声/混响泄漏），社区评价好
- ✅ 标注性别/音域匹配（Angela=清澈女声、Neo=温和男声）
- ✅ 文件较新（v2 48k/f0），与你的 RVC 版本兼容
- ❌ 避开"某个当红歌手本人"模型用于公开路演（见 §1）

**各备 2-3 个候选**，听验后定（§6）。放 `packages/voice/models/{angela,neo}/`。

## 3. 环境（5070Ti 12G）

```bash
cd packages/voice
# 方式 A：rvc-python（轻量，命令行/脚本调用，推荐）
pip install rvc-python torch torchaudio   # CUDA 版 torch（适配 5070Ti，需较新 torch+cu12x）
# 方式 B：Applio（GUI/CLI，功能全，适合试模型）
# 按 Applio 仓库装；5070Ti 12G 跑 inference 绰绰有余
```
> 5070Ti 是 Blackwell 架构，**需要较新的 CUDA toolkit + PyTorch（cu126/cu128 级）**；老版本 torch 可能不识别卡。装不上先升级 torch。
> 12G 显存：RVC 推理只需 2-4G，余量充足；可同时开 batch。

## 4. 推理流程

```bash
# rvc-python CLI（参数名按你装的版本微调）
rvc-pipe -m models/angela/angela.pth -ir models/angela/angela.index \
         -i "传奇 vocals.wav" -o "传奇 vocals_angela_rvc.wav" \
         -p 0 -f0 rmvpe -t 0 -r 0.5   # 见 §5 调参
```
- 或 Applio GUI：选模型→输入源人声→调 pitch/f0/method/index ratio→Convert。
- 两曲分别跑（Angela 用传奇人声、Neo 用因为爱情男声）。
- 5070Ti：一首 3-4 分钟的歌，**几十秒到两分钟**出结果，可反复试。

## 5. 调参（决定听感）

| 参数 | 含义 | 建议起点 |
|------|------|----------|
| `pitch_shift` / `-p` | 整体升/降半音 | **同性别模型用 0**；男模转女声 +12，女模转男声 -12 |
| `f0_method` | 基频提取 | `rmvpe`（质量/速度均衡）；要极致质量用 `crepe`（慢） |
| `index_ratio` / `-r` | 用 .index 索引贴音色 | 有 index 用 **0.5–0.7**；无 index 设 0 |
| `protect` / `-t` | 保护清辅音/气声防电音 | **0.33–0.5**（越大越保守） |
| `filter_radius` | 中值滤波平滑音高 | 默认 3 |
| 混音比 | 原声/变声 | 以 `vocal_rvc` 为准；混音时人声略高于伴奏 |

调参顺序：先定 `pitch_shift`（性别/音域对）→ 调 `index_ratio` 贴音色 → 调 `protect` 去电音。

## 6. 质量验收

逐项听验 `*_rvc.wav`：
- [ ] 音准对（没跑调、没机械音阶感）
- [ ] 无明显电音/机器人味（辅音、气声自然）
- [ ] 音色统一（整首一致，不忽男忽女）
- [ ] 咬字清晰（歌词能听清）
- [ ] 与伴奏调性匹配（不打架）

不达标：换候选模型（§2 各备 2-3 个）→ 调参 → 仍不行走 §8 兜底。

## 7. 对白上色（intro/outro 可选）

让对白音色与唱歌统一：edge-tts 出声（女/男）→ 再过对应 RVC 模型。
- edge-tts 选中性声线（zh-CN-XiaoyiNeural 等）→ RVC(Angela)；男声 → RVC(Neo)。
- 来不及就**直接用 edge-tts 原声**，对白不烤（路演可接受）。

## 8. 兜底（烤不达标 / 来不及）

| 情况 | 兜底 |
|------|------|
| RVC 电音重、调不好 | 用**原人声**直接混进伴奏带跑通流程（数字人声=原唱，先求能演） |
| 想要更好听、有时间 | **请人录+修音**（真人录 Angela/Neo 声部，修音准/时值），数字人对口型——听感最好、风险最低 |
| 模型加载失败 | 换模型版本；确认 torch+CUDA 识别 5070Ti |
| 5070Ti 不识别 | 升级 torch 到 cu126/cu128；或租云 GPU 跑离线推理 |

> 路演前：**至少有一版能用的数字人声进伴奏带**（哪怕是原声兜底），别临场才烤。
