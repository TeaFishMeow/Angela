# 01 · 三小时开发计划

> 3 小时、3 个人、1 个能演示的合唱模式。**关键是并行走、mock 先行、按 checkpoint 对齐。**
> 时间是硬约束，文档/契约已经先冻结（见 `02`、`03`），大家直接照着干。

---

## 0. 铁律

1. **契约先冻结，别再改 `02/03`。** 字段名就是合同，照抄。
2. **mock-first。** 每人都先对着 `data/samples/` 和 `packages/backend/mock/mock_ws.py` 跑通自己那块，**不要等别人**。
3. **每个 checkpoint 必须能"亮一下"**（屏幕上有东西在动），不追求完美。
4. **大文件不入 git**（见 `.gitignore`），用网盘/U 盘传 stems/MV/模型。
5. **砍范围保时间**：见 `00 §7 非目标`，超时的功能直接删。

## 1. 三人主线（并行）

| 时段 | 你（架构/整合/MV/分轨） | 队友 A（数字人） | 队友 B（后端） |
|------|------------------------|------------------|----------------|
| C0 setup | 建 repo、推文档、冻结契约 | clone、装 pixi-live2d-display、找/放模型 | clone、建 FastAPI 骨架、装依赖 |
| C1 骨架 | 舞台三幕静态页 + mock WS 跑通 | Live2D 加载 + `setViseme/playMotion/idle` API | `/api/songs` + `/ws` echo + mock `song.tracks` |
| C2 对接 | 接数字人槽位；主时钟主循环 | 接 mock viseme 帧动嘴；接 action 动作 | TTS（edge-tts）+ 对白口型帧实时推 |
| C3 真数据 | 稻香分轨+编排+塞进 assets | 真模型 + 真动作 + 右侧透明叠层 | RVC 变声 + 混音 mix.wav + 预烘焙 visemes |
| C4 联调 | 端到端三幕、调时序 | 表情/动作微调 | 音量/延迟/纠偏 |
| C5 演练 | 走一遍完整 demo + 兜底预案 | 同 | 同 |

## 2. Checkpoint 时间表（含 30min 缓冲）

> 假设 T0 = 开始。每个 C 约 30min，留最后 30min 演练+兜底。

### C0 · T0–T20 · 冻结与起跑
- **你**：`git init` + 推文档到远程；建 `packages/{stage,backend,character}` 空目录 + 占位 README；把 `data/samples/` 确认无误。
- **A/B**：clone 仓库，装环境，能 `import`/`require` 成功。
- **交付物**：仓库可访问、文档就位、目录就位。

### C1 · T20–T50 · 各自骨架 + mock 跑通 ★
- **你（stage）**：`index.html` 三幕静态版（MV 占位图/黑底、歌词双栏空壳、右侧占位框）；用 **mock_ws.py** 跑通"选歌→合唱（假进度）→收尾"状态机。
- **A（character）**：`packages/character/character.js` 暴露：
  ```js
  const angela = await Character.mount(canvasEl, { model: 'angela.model3.json' });
  angela.setViseme({ ParamMouthOpenY: 0.6 });
  angela.playMotion('singing_high', { loop: true });
  angela.idle();
  ```
  先用任意现成 Live2D 模型验证 API。
- **B（backend）**：FastAPI 起 `/api/songs`（返回 `data/samples` 里的歌单）、`/ws`（收到 `hello` 回歌单、收到 `song.start` 回 mock `song.tracks` + `song.start` + 定时 `song.tick`）。
- **交付物**：三方各自能在本地"亮起来"，互不依赖。

### C2 · T50–T80 · 两两对接
- **你 + A**：把 `character.mount()` 接进舞台右侧 canvas；主循环里用 mock visemes 动嘴、mock actions 切动作。**此时数字人在 MV 前会动。**
- **你 + B**：舞台连真后端 `/ws`，选歌/合唱/收尾状态由后端 `phase.change` 驱动；合唱期主时钟主循环跑起来（仍用 mock mix.wav，可随便放个音频）。
- **B**：接 edge-tts，幕一/幕三能实时推 `tts.*` + `viseme.frame`（口型先用幅度法）。
- **交付物**：前端 + 后端真连、前端 + 数字人真连。

### C3 · T80–T130 · 灌真数据 ★（最吃时间）
- **你**：稻香分轨（Demucs）→ 人工切高/低声部 → 喂给 B 的 RVC → 混音出 `mix.wav`；写 `lyrics.json`（带时间戳）；MV 放进 `assets/`。
- **B**：RVC 把高声部转 Angela 音色；混音 `instrumental + angela_rvc + neo` → `mix.wav`；由 `angela_rvc.wav` 算 `visemes.json`（librosa RMS@30fps）；产出 `song.json`。
- **A**：放真 Angela 模型 + 录/挑动作（idle/singing_high/wave…）；右侧透明叠层 + 表情。
- **交付物**：assets 里有真 mix/MV/stems；轨道 JSON 全部真实。

### C4 · T130–T160 · 端到端联调
- 全员在**一台演示机**上跑：stage + character + backend 同源。
- 顺一遍：选歌口型对不对 → 合唱嘴音同步 → 歌词高亮时机 → 动作切点 → 收尾口型。
- 调音量比例、TTS 音色（是否叠 RVC）、口型幅度映射。
- **交付物**：能完整跑完三幕。

### C5 · T160–T180 · 演练 + 兜底
- 完整走 2 遍 demo，掐时间。
- 准备兜底：① 后端挂了 → 前端切"离线模式"（本地播 mix.wav + 本地轨道 JSON）；② Live2D 加载失败 → 显示静态立绘 + 幅度驱动嘴；③ RVC 来不及 → 直接用原人声跑通流程。
- **交付物**：可演示 + 有 Plan B。

## 3. 依赖与"卡点"提醒

- **最易卡点 = RVC 变声 + 混音（C3）**。如果 T110 还没出 `mix.wav`：**立刻降级**——用原人声直接混音跑通流程，RVC 视作"锦上添花"，demo 前能上就上。
- **第二卡点 = Live2D 模型资产**。A 必须在 C0 就确认有可用模型；没有就用任意免费 Live2D 样例模型占位，名字先叫 Angela。
- **第三卡点 = 歌词时间戳**。手打耗时，C3 优先打"主歌+副歌"即可，间奏/尾奏空着没事。

## 4. 每日（本次）"集成节奏"

- 每个 checkpoint 结束，**你（整合者）**做一次集成提交 + 在群里喊"C2 通了，可以接"。
- A/B 各自分支开发，checkpoint 时合到主干（本 demo 可直接主干提交，省 PR 流程）。

## 5. 风险与降级表

| 风险 | 触发条件 | 降级方案 |
|------|----------|----------|
| RVC 不及出 | T110 无 mix | 原人声混音，跳过变声 |
| 数字人加载失败 | Live2D 报错 | 静态 PNG + 幅度驱动嘴 |
| WS 抖动 | 口型/歌词乱 | 合唱期本来就靠本地时钟，几乎不受影响；对白期降级为预录 wav |
| MV 没素材 | 没有 mv | 用歌词背景图/可视化频谱代替 |
| 演示机没装环境 | 跑不起来 | 全打包成静态站 + 录屏备份 |

→ 接口细节见 `02`，数据字段见 `03`，联调步骤见 `08`。
