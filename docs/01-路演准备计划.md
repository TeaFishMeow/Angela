# 01 · 路演准备计划

> 路演版（两曲/两数字人/队友C现场）。**不再是 3 小时冲刺**，而是分阶段倒推路演日期。
> 铁律不变：**契约先冻结、mock-first 并行、每阶段都能"亮一下"、砍范围保时间。**

---

## 0. 铁律

1. **契约先冻结**（`02`/`03`），字段名即合同。
2. **mock-first**：每人对着 `data/samples/` 与 `mock_ws.py` 先跑通自己那块，不等别人。
3. **每阶段交付物可演示**，不追求完美。
4. **大文件不入 git**（`.gitignore`），用网盘/U 盘传 MV/stems/模型。
5. **现场兜底优先级最高**：宁可少一个动作，不能现场翻车。

## 2. 各阶段详情

### P0 · 冻结与起跑
- **你**：建 `packages/{stage,backend,character,voice}` 空目录 + 占位 README；确认 `演示用例/` 素材；`mock_ws.py` 可跑。
- **A/B**：clone、装环境、`import`/`require` 成功。
- 交付：仓库可访问、目录就位、`演示用例/因为爱情_分轨` 已有男声+伴奏。

### P1 · 各自骨架 + mock ★
- **你（stage）**：`index.html` 两场静态版（MV 占位、双声部歌词壳、右侧占位、场切换按钮）；用 `mock_ws.py` 跑通"场1→场2"状态机。
- **A（character）**：`character.js` 支持**多模型**：
  ```js
  const stage = await Character.mount(canvas);
  await stage.use('angela'); await stage.use('neo');   // 预载两个模型
  stage.setViseme(...); stage.playMotion('singing_high'); stage.switchTo('neo');
  ```
  先各用一个现成 Live2D 样例模型验证 API（一女一男）。
- **B（backend）**：`/api/scenes`（两场）、`/ws`（hello→scene.list；scene.start→scene.tracks+scene.start+tick→scene.end）。
- 交付：三方各自本地能"亮"。

### P2 · 两两对接
- **你 + A**：右侧接数字人；mock visemes 动嘴、mock actions 切动作；**场间能切换 Angela↔Neo**。
- **你 + B**：连真后端；intro/合唱/outro 由后端 `scene.*` 驱动；主时钟主循环跑起来（用任意音频当伴奏带）。
- **B**：edge-tTS，intro/outro 实时推 `tts.*`+`viseme.frame`。
- 交付：前端+后端真连、前端+数字人真连、两场可手动切换。

### P3 · 烤声 + 灌真数据 ★（最吃时间）
- **B（烤声，见 `09`）**：
  - 因为爱情：`因为爱情 男声_vocals.wav` → RVC(Neo 男模型) → `neo_rvc.wav`；与 `因为爱情 男声_instrumental.wav` 预混 → `因为爱情_backing.wav`。
  - 传奇：Demucs 分轨 → `传奇 vocals.wav` → RVC(Angela 女模型) → `angela_rvc.wav`；与伴奏预混 → `传奇_backing.wav`。
  - 由两条 rvc 人声烘焙 `visemes.json`。
- **你**：两曲 `lyrics.json`（带时间戳、声部标 digital/teammateC）；MV 裁到与伴奏带同长；写 `scene.json`。
- **A**：放真 Angela/Neo 模型 + 动作；右侧透明叠层。
- 交付：`演示用例/` 里两曲伴奏带 + 轨道 JSON 全真实。

### P4 · 现场麦 + 联排
- **调音**：伴奏带 lineout → 调音台；队友C 麦 → 调音台 → PA；队友C 返听 = 伴奏带 + 自己。
- **联排**：在一台演示机上跑全套，顺两场：intro→合唱→outro→（切）→第二场。
- 调音量比例（伴奏带 vs 队友C 麦）、返听平衡、口型幅度。
- 交付：两场串行走完、现场音响通。

### P5 · 路演 + 兜底
- 走场 2 遍，掐时间。
- **兜底**（见 `08 §7`）：后端挂→前端离线播伴奏带+本地轨道；Live2D 挂→静态立绘；RVC 来不及→原声或录+修音；**全程录像备份**。

## 4. 卡点与降级

| 卡点 | 触发 | 降级 |
|------|------|------|
| **RVC 烤声不及/效果差** | P3 出不来或电音重 | 用原人声跑通；或**录+修音**（见 `09 §兜底`）；路演前能换再换 |
| **社区模型音色不合规/不贴** | 选到明星音色有风险 | 换自有/合成音色；详见 `09 §合规` |
| **男 Live2D 模型难找** | Neo 模型缺 | 用 VRM/3D 男模，或简化 Neo（PNG+口型） |
| **传奇分轨不干净** | 人声残留 | 换 htdemucs_ft / UVR5 MDX23C |
| **现场返听/延迟** | 队友C 跟不上 | 伴奏带直接进返听，不经电脑；队友C 不跟屏幕 |
| **演示机性能** | MV+两 Live2D 掉帧 | MV 降 1080p；非当前场模型卸载 |
